# hyperplace.org

Landing page for Hyperplace's protocol and public home: an open,
self-sovereign spatial identity primitive.

Plain static HTML/CSS, deployed on Vercel. See `STATUS.md` for current
build state and `CLAUDE.md` for constraints (design source, fonts,
content rules).

## Development

Any static file server works, e.g.:

```bash
npx serve public
```
